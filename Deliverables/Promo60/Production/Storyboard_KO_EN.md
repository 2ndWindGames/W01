# 네온터치 / VioletTap — 60초 세로 홍보 영상 편집 대본

상태: 제작 준비본. 아래 시각은 편집 목표이며, 아직 녹음·촬영·최종 재생 검증을 완료하지 않았습니다.

## 공통 사양과 연출

- 언어별 영상 1개씩, 각각 60.000초 / 1080×1920 / 9:16 / MP4(H.264, yuv420p, AAC stereo).
- 실제 Unity 게임 화면만 게임 플레이로 사용. 캐릭터를 새로 만들어 실제 게임 요소처럼 보여 주지 않음.
- 게임 화면은 비율을 유지하고 전체 HUD와 터치 영역을 프레임 안에 보존. 설명 자막이 콤보·타이머·타겟을 가리지 않도록 분리.
- 상단 게임명과 짧은 핵심 문구, 중앙 실제 게임 화면, 하단 2줄 이내 내레이션 자막. 우측 플랫폼 버튼과 하단 설명 영역을 고려해 중요 문구를 안쪽에 배치.
- 한국어 영상에는 한국어 게임 UI, 영어 영상에는 영어 게임 UI 사용.
- 게임의 시간 진행, 타겟 수명, 점수, 콤보 수치를 홍보 목적으로 조작하지 않음. 서로 다른 실제 플레이 구간을 편집한 영상임을 제작 기록에 명시.
- 나레이션은 합성 음성. 사람 성우 녹음이라고 표기하지 않음. 짧은 문장별로 리액션과 호흡을 살리되 전체를 고음·고속으로 읽지 않음.
- 음악은 프로젝트의 Gameplay_NeonRush / Gameplay_ComboDrive / Gameplay_ComboRush를 활용. 타격·피버·폭탄·종료 효과음은 실제 촬영 이벤트에 맞춰 동기화.
- 배경음은 나레이션 구간에 낮추고 문장 사이에서 회복. 최종 AAC 재인코딩 후 클리핑·무음·발음·자막 동기를 검사.
- 출시일, 정식 출시 여부, 무료 여부, 다운로드 수, 실제 순위 등 확인되지 않은 정보를 넣지 않음.

## 음성 디렉션

English: conversational, playful, clear. Build energy into Fever, pull back for the bomb reaction, and land the final CTA calmly. Avoid a constant announcer voice or exaggerated pitch shifts. Read VioletTap as “Violet Tap.”
