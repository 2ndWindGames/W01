# 네온터치 / Violet Tap 3.6 출시 노트

- 버전 이름: 3.6
- Android 버전 코드: 9
- 패키지 이름: com.secondwindgames.violettap
- 작성일: 2026-09-14

## 한국어 (ko-KR)

- 콤보 수, 점수 배율, 피버 게이지를 한눈에 확인할 수 있는 전용 UI를 추가했습니다.
- 콤보 실패 시 화면 효과, 효과음과 진동 피드백을 강화했습니다. 타겟을 놓치거나 폭탄을 누르면 피버가 종료됩니다.
- 시간이 지날수록 타겟이 더 빠르게 사라지도록 플레이 속도감을 높였습니다.
- 랭킹의 점수 잘림과 긴 닉네임 표시를 개선했습니다.
- 게임 종료 후 남는 네온 잔상과 안내 문구 겹침을 수정했습니다.

## English (en-US)

- Added a dedicated combo HUD with score multipliers and a Fever meter.
- Enhanced combo-break effects, sounds and haptic feedback. Misses and bombs now end Fever.
- Targets disappear faster as the round progresses for more intense gameplay.
- Improved ranking layout to prevent clipped scores and handle long nicknames.
- Fixed lingering neon effects after rounds and overlapping status messages.

## 배포 전 확인 (스토어에 붙여넣지 않음)

- 이 작업은 프로젝트 버전과 출시노트만 갱신합니다. 기존 APK/AAB 파일의 버전은 바뀌지 않으므로 3.6 (9)으로 새 AAB를 빌드해야 합니다.
- 기존 서명키와 패키지 이름을 유지해야 기존 앱의 업데이트로 배포할 수 있습니다.
- 6시간 QA는 Unity Editor에서 완료했습니다. Android 실기기의 진동·사운드·성능과 스토어 결제 검증을 대체하지 않습니다.
