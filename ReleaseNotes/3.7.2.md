# 네온터치 / Violet Tap 3.7.2 출시 노트

- 버전 이름: 3.7.2
- Android 버전 코드: 12
- 패키지 이름: com.secondwindgames.violettap
- 작성일: 2026-09-14

Google Play에 붙여넣을 언어 태그 형식: [3.7.2-google-play.txt](3.7.2-google-play.txt)

## 한국어 (ko-KR)

- 새로운 네온 앱 아이콘을 적용했습니다.
- 빠른 연속 터치에서도 타깃이 정확히 인식되도록 개선했습니다.
- 일부 화면 크기에서 순서 타깃 배치 실패로 진행이 멈추던 문제를 수정했습니다.
- 랭킹에서 긴 닉네임과 큰 점수의 가독성을 개선했습니다.
- 필요한 경우 설정 화면에 개인정보 설정 버튼이 표시됩니다.

## English (en-US)

- Added a new neon app icon.
- Improved target detection during rapid consecutive taps.
- Fixed an issue that could stall gameplay when numbered targets could not fit on screen.
- Improved leaderboard readability for long names and high scores.
- Privacy options now appear in Settings when required.

## 배포 메모 (스토어에 붙여넣지 않음)

- Windows Android 빌드 경로 문제를 수정했습니다. 3.7.2 AAB는 빌드 오류 0건으로 생성되었고 서명 및 번들 검증을 통과했습니다.
- 실기기 광고·결제·성능 검사는 이번 배포에서 사용자 요청에 따라 생략했습니다.
