# 네온터치 3.3 출시 노트

## 한국어 (ko-KR)

네온터치의 전체 그래픽을 새로운 네온 스타일로 개편했습니다.
인트로, 게임 화면, HUD, 버튼, 팝업과 랭킹 화면 디자인을 개선했습니다.
일반, 퀵, 시간 보너스, 폭탄 타겟을 쉽게 구분할 수 있도록 전용 디자인을 적용했습니다.
버튼 반응과 화면 가독성을 개선하고 UI 리소스를 최적화했습니다.

## English (en-US)

Refreshed Neon Touch with a new visual style.
Improved the intro, gameplay HUD, buttons, popups, and ranking screen.
Added distinctive designs for normal, quick, time bonus, and bomb targets.
Improved button feedback, readability, and UI asset optimization.
