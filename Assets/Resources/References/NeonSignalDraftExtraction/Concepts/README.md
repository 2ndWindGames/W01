# Neon Signal 전체 리소스 시안

기존 네이비 배경, 시안·바이올렛·핑크 네온, 각진 SF 프레임을 유지하면서 화면 계층과 게임 규칙 전달력을 강화한 통합 아트 방향입니다.

## 시안 보드

- `01_intro_scene.png`: 타이틀, 에너지 코어, 시작 버튼, 게임 방법, 회사/제작자, 사운드·랭킹·설정 버튼
- `02_gameplay_states.png`: Ready, Playing, Fever, Result 상태와 HUD, 플레이 필드, 광고 제거 버튼
- `03_popup_suite.png`: 랭킹, 설정, 사운드 팝업과 공통 닫기 동작
- `04_targets_and_vfx.png`: 일반, 퀵, 시간, 정밀, 이동, 위험, 과부하 타깃 및 타격 효과
- `05_ui_kit.png`: 패널, 버튼 상태, HUD 카드, 게이지, 콤보, 등급, 토글, 슬라이더, 랭킹 행, 공통 아이콘

## 제작 프롬프트 요약

모든 보드는 `ui-mockup` 또는 `stylized-concept` 용도로 생성했습니다. 공통 요청은 짙은 네이비 배경, 시안·바이올렛·핫핑크·금색 포인트, 얇은 각진 HUD 프레임, 절제된 글로우, 높은 가독성, Unity에서 분리 제작 가능한 2D 구조입니다. 캐릭터, 워터마크, 광고, 과도한 블룸은 제외했습니다.

이 이미지는 최종 게임에 바로 넣는 합성 이미지가 아니라, 개별 PNG와 프리팹을 제작하기 위한 기준 시안입니다.
