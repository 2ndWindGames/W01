# Neon Touch social video delivery

Four separate 1080 × 1920 vertical H.264/AAC promos: Instagram Reels (24 seconds) and YouTube Shorts (39 seconds), each in Korean and English. Covers, optional SRT narration captions, and ready-to-edit publishing copy are supplied alongside them.

The visual panels use actual W01 game screenshots, framed against game-derived neon graphics. These are edited promotional compositions, not recordings of continuous live gameplay. The narration uses short, expressive synthesized takes with varied pacing and music ducking; it is **not** a human voice actor recording. The publishing kit includes actor direction should a human VO be recorded later. No store URL is invented; replace the placeholder in YouTube descriptions after publishing.

Regenerate with `Tools/build_social_videos.py` in the project workspace. Generated intermediates are under `work/`; deliver only the four MP4 files, four covers, four SRT files, and `Publishing-Kit/`.
